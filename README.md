## ✨ À propos du projet

**Priscilla Mezouar** est un site vitrine conçu pour **présenter mon expérience, mes compétences et mes projets**. Il permet aussi de **faciliter la prise de contact**.

Ce projet a été conçu dans le but de proposer un site vitrine moderne, intuitif et facilement maintenable.

---

## 🎯 Objectifs

* 💻 Valoriser mes compétences et mon expériences
* 📖 Présenter mes projets
* 📩 Simplifier la prise de contact

---

## 🧠 Approche technique

Ce projet a été développé avec une attention particulière portée à :

* 🔎 La navigation
* 📱 L’accessibilité et le responsive design
* 📈 L'évolution et la maintenabilité

---

## 🛠️ Stack technique

### Frontend

* React
* Vite
* TypeScript
* HTML5
* CSS3

### API

* Formspree (pour l'envoi sécurisé du formulaire de contact)


### Outils

* Git / GitHub
* VS Code
